Rastro de cada revisão.

Uma API para organizar resumos científicos, identificar pontos de atenção na escrita e manter um histórico verificável das análises.

Abrir API navegável ↗Entrar na demonstração
01 / ORGANIZAR

Seus artigos, seu espaço

Cadastre título, idioma e resumo. Pesquise seus textos com paginação e acesso restrito ao proprietário.

02 / REVISAR

Observações objetivas

Encontre repetições consecutivas e frases longas, com contagem de palavras e frases em cada análise.

03 / ACOMPANHAR

Histórico preservado

Um texto alterado gera uma nova revisão. Repetir a análise do mesmo conteúdo reutiliza o resultado existente.

Experimente localmente

O backend é o produto.

Crie o usuário com python manage.py seed_demo, entre na API navegável e cadastre um artigo. Use o endpoint de revisão para gerar a análise.

A revisão usa regras locais e determinísticas. Não utiliza IA, não traduz textos e não verifica validade científica.

POST   /api/auth/token/
GET    /api/papers/
POST   /api/papers/
PATCH  /api/papers/{id}/
POST   /api/papers/{id}/review/
GET    /api/papers/{id}/reviews/
